
# Week 8 Final Project: Personal Mini-Toolkit

## Project Description

My Personal Mini-Toolkit is a Python program that provides three useful tools through a simple menu.

## Tools Included

1. **Simple Calculator:** Performs addition, subtraction, multiplication and division.
2. **To-Do List:** Allows users to add, view and remove tasks.
3. **Number Guessing Game:** Lets users guess a secret number between 1 and 20.

## How to Run the Program

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python toolkit.py
```

5. Choose a tool from the menu and follow the instructions.

## Python Concepts Used

- Variables and data types
- User input and output
- If, elif and else statements
- While and for loops
- Lists and list methods
- Functions
- F-strings
- Try and except error handling

## Project Reflection

The hardest part of this project was creating the menu loop and making sure each tool returned to the main menu correctly. The bug that took the longest to fix was handling invalid user input without crashing the program. I learned how to use lists to store tasks and how to update them while the program runs. I also improved my understanding of loops and conditional statements. Testing each tool helped me find and correct mistakes. If I had one more week, I would add a feature that saves the to-do list in a file. I would also improve the design of the menu and add more useful tools.
